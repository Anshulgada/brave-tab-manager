# Changelog

All notable changes to Tabman will be documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.3.6]

### Added

- Offline Tabman CLI with vault import/export, search, capture, and organize.

## [0.3.5]

### Added

- Dexie IndexedDB persistence with migrations and shared-fixture import/export.

## [0.3.4]

### Added

- SQLite vault persistence with guarded legacy JSON/Markdown import.

## [0.3.3]

### Added

- Versioned shared schema contract with Pydantic and Zod mirrors plus fixture tests.

## [0.3.2]

### Added

- WXT React extension scaffold with side panel, dashboard, and local typography.

## [0.3.1]

### Added

- Monorepo hooks, dual-stack CI, hygiene files, and shared schema stub.

## [0.3.0]

### Changed

- Began the dual-surface rebuild with a Python CLI src layout and uv packaging.

## [0.2.1]

- Legacy Python CLI release before the dual-surface rebuild.
